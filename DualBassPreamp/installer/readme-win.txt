DUALBASSPREAMP 1.0.0
=====================

DualBassPreamp is a 64-bit VST3 bass preamp and drive effect published by
Play Tempo.

INSTALLATION
------------

The installer places the plug-in in:

C:\Program Files\Common Files\VST3\DualBassPreamp.vst3

Restart the DAW after installation. If the plug-in is not listed, run the
DAW's plug-in rescan command.

The interface has a fixed size of 960x600 pixels.
