# Modern Metal Bass

The Audio Unit and VST3 plug-ins will be installed in the standard system
plug-in folders and will be available to all user accounts on this Mac.

GarageBand and Logic Pro use the Audio Unit version. Other DAWs may use the
VST3 version. Click **Customize** on the **Installation Type** page if you do
not want to install both formats.

Restart the DAW after installation. The first launch may take longer while the
plug-in is scanned.

Start with the **Modern Metal** preset, then adjust Input and Input Shape for
your bass and audio-interface level.
