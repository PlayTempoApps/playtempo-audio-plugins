MODERN METAL BASS 0.4.1 - WINDOWS X64 VST3
Published by Play Tempo

INSTALLATION

1. Close Ableton Live and any other DAW.
2. Extract the ZIP file.
3. Copy the complete ModernMetalBass.vst3 folder to:

   C:\Program Files\Common Files\VST3\

4. Windows may request administrator permission. Approve it.
5. Open the DAW and rescan VST3 plug-ins if Modern Metal Bass is not listed.

The final installed path must be:

C:\Program Files\Common Files\VST3\ModernMetalBass.vst3\Contents\x86_64-win\ModernMetalBass.vst3

UNINSTALLATION

Close the DAW and delete:

C:\Program Files\Common Files\VST3\ModernMetalBass.vst3

This portable package is intended for private testing. The Windows binary
should be Authenticode-signed before public distribution.
