MODERN METAL BASS 0.4.1
=======================

Modern Metal Bass is a 64-bit VST3 multiband processor for tight, distorted,
mix-ready metal bass tones, published by Play Tempo.

INSTALLATION
------------

The installer places the plug-in in:

C:\Program Files\Common Files\VST3\ModernMetalBass.vst3

Restart the DAW after installation. If the plug-in is not listed, run the
DAW's plug-in rescan command.

The interface has a fixed size of 960x600 pixels.
